# 📚 Kumpulan Tugas Praktikum React JS

Selamat datang! Repositori ini berisi kumpulan tugas serta latihan **Pengembangan Frontend dengan React JS**, mulai dari pertemuan 1 hingga akhir.

## 🛠️ Tech Stack

Proyek ini dibangun menggunakan teknologi berikut:
*   **React JS** (Library JavaScript untuk membangun User Interface)
*   **Vite** (Build tool modern untuk pengembangan yang cepat)
*   **Bootstrap 5** (Framework CSS untuk styling dan layout responsif)
*   **JavaScript (ES6+)**
*   **FontAwesome** (Untuk ikon)
